Strictly Spending — Privacy Policy

Last Updated: October 25, 2026 · App ID: com.strictlyspending.app

Strictly Spending is a local-first personal finance, budgeting, and cashflow forecasting application. Your financial privacy is our foundational architectural principle.

1. Zero Cloud Collection & On-Device SQLite Storage

Strictly Spending does not operate remote servers, user accounts, or cloud databases. All financial records—including bank accounts, transactions, categories, categorization rules, budgets, loans, and forecast scenarios—are stored exclusively inside a local SQLite database on your personal device. The application contains zero third-party analytics SDKs, advertising identifiers, or behavioral trackers.

2. Optional Bank Synchronization (SimpleFIN Bridge)

If you choose to configure automatic bank synchronization via SimpleFIN Bridge, your SimpleFIN Access Token/URL is stored locally in your on-device SQLite database. When you initiate a bank sync, your device communicates directly with SimpleFIN (https://beta-bridge.simplefin.org) over encrypted HTTPS (TLS) to retrieve read-only account balances and transaction histories. Strictly Spending never proxies, intercepts, or stores your banking credentials or SimpleFIN tokens on any external server.

3. Optional Local AI & Model Context Protocol (MCP) Integration

Strictly Spending includes an optional local Model Context Protocol (MCP) server that allows you to connect local AI clients (such as Claude Desktop, Cursor, or Antigravity) to your on-device SQLite database. This interface runs locally on your machine via standard input/output (stdio) or local network HTTP only when explicitly launched by you.

4. Data Portability, Retention & Complete Deletion

  • Full Data Portability: You can export your entire database to a human-readable JSON backup file at any time from the Import & Backup screen.
  • Instant Data Deletion: Because all data resides locally on your device, you can permanently delete all imported financial data at any time by navigating to Settings → Imported data → Clear all imported data, or by uninstalling the application from your device.

5. Contact & Open Source Transparency

If you have questions regarding this Privacy Policy or Strictly Spending's security architecture, please open an issue on our official repository at https://github.com/barnesy/strictly-spending.
